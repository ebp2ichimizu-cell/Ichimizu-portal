# 01_ポータルサイト_構築運用仕様

基準日：2026-09-24

## 1. サイト概要

目的：いちみず会関連サイトへの入口を一本化する。

公開URL：  
https://ebp2ichimizu-cell.github.io/Ichimizu-portal/

GitHub：  
`ebp2ichimizu-cell/Ichimizu-portal`

特徴：
- 1ページ型静的ポータル
- 日本語／英語切替
- JSON駆動
- PWA対応
- QRコード共有

## 2. システム構成

```text
/
├─ index.html
├─ sites.json
├─ meeting.json
├─ recommendations.json
├─ manifest.json
├─ service-worker.js
├─ IMG_2260.png
├─ portal-qr.png
├─ apple-touch-icon.png
├─ icon-192.png
├─ icon-512.png
└─ README.md
```

### index.html
サイト本体。HTML、CSS、JavaScriptを1ファイルに保持。ヘッダー、ロゴ、言語切替、会合、おすすめ、主要サイト、QR、フッター、JSON読込、Service Worker登録を担当。

通常のコンテンツ追加では変更しない。

## 3. コンテンツ・データ構造

### sites.json
主要サイトカード一覧。

主な項目：
- `id`
- `title_ja`, `title_en`
- `description_ja`, `description_en`
- `url_ja`, `url_en`
- `category_ja`, `category_en`
- `updated`
- `status`（`preparing` で準備中）

### meeting.json
主な項目：
- `active`
- `meeting_no`
- `date`
- `date_ja`, `date_en`
- `time`
- `title_ja`, `title_en`
- `themes_ja`, `themes_en`
- `presenters_ja`, `presenters_en`
- `zoom_url`
- `chat_url`

### recommendations.json

```json
{
  "ichimizu_columns": [],
  "daily_brief": []
}
```

主な項目：
- `id`
- `title_ja`, `title_en`
- `summary_ja`, `summary_en`
- `url_ja`, `url_en`
- `category_ja`, `category_en`
- `active`
- Daily Brief系は `date`

### 画像・PWA
- `IMG_2260.png`：ロゴ
- `portal-qr.png`：QRコード
- `manifest.json`、`service-worker.js`、各種アイコン：PWA関連

## 4. 更新・運用方法

- サイト追加・修正：`sites.json`
- 次回会合：`meeting.json`
- おすすめ：`recommendations.json`
- 日英固定文言：`index.html` 内 `translations`

原則触らない：
- `index.html`
- `manifest.json`
- `service-worker.js`
- アイコン類

## 5. 再構築・復旧手順

優先順位：
1. `index.html`
2. `sites.json`
3. `meeting.json`
4. `recommendations.json`
5. ロゴ・QR
6. `manifest.json`
7. `service-worker.js`
8. PWAアイコン

GitHub Pagesの公開ルートは現行どおりリポジトリ直下とする。
